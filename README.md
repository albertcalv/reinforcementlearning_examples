# Reinforcement Learning examples

This repository contains examples of reinforcement learning (RL) implemented using Gymnasium.

## Installation
To install Gymnasium along with all optional dependencies, run: `pip install gymnasium[all]`. Alternatively, if you prefer using uv, create a virtual environment and install the project dependencies as follows:

```bash
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt
```
